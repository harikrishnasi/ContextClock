# ContextClock

AI chatbots understand conversations. They don't understand time.
ContextClock fixes that.

## Overview
Most AI chatbots lack the concept of real-world elapsed time between messages. ContextClock is a lightweight browser extension that prepends real-world time contexts (like time of day, date, and time elapsed since last message) to your inputs before sending them to the AI. This restores the conversational and emotional continuity.

## Features
- **Temporal Context Injection:** Automatically adds formatted timestamps.
- **Elapsed Time Awareness:** Tells the AI if it's been 9 hours since the last message.
- **Multi-Platform Support:** Works seamlessly with ChatGPT, Claude, and Gemini.
- **Privacy First:** Fully local. No tracking, no external servers.

## Installation
1. Download or clone this repository.
2. Go to `chrome://extensions/` in your browser.
3. Enable "Developer mode".
4. Click "Load unpacked" and select the `ContextClock` folder.

## Privacy
No analytics.
No tracking.
No external servers.
Everything runs locally on your machine.
