# ContextClock — Privacy Policy

## Overview

ContextClock is designed with a strict privacy-first philosophy.

The extension does not collect, transmit, sell, or store personal data externally.

Everything operates locally inside your browser.

---

# Data Collection

ContextClock does NOT:

- collect personal data
- collect conversations
- collect prompts
- collect AI responses
- track browsing history
- use analytics
- use advertising systems
- fingerprint users
- sell data
- send data to external servers

---

# Local Storage

ContextClock may store lightweight settings locally using Chrome extension storage.

Examples:

- extension enabled/disabled state
- platform toggles
- badge preferences
- elapsed-time timestamps

This information:

- stays inside your browser
- is never transmitted externally
- is only used for extension functionality

---

# AI Conversations

ContextClock modifies messages locally before they are sent to supported AI platforms.

The extension does not intercept or store conversations externally.

Any modified message is only sent directly to the AI platform you are actively using.

Example:

```text
[Morning · May 14 2026 · 8:42 AM]
```

This metadata becomes part of the message you intentionally send.

---

# Permissions

ContextClock requires limited browser permissions to:

- access supported AI websites
- inject timestamp context
- store local extension preferences

The extension does not request unnecessary permissions.

---

# Third-Party Services

ContextClock does not use:

- third-party analytics
- remote databases
- external APIs
- tracking SDKs
- advertising networks

---

# Security

ContextClock is designed to minimize risk by:

- running entirely locally
- avoiding backend infrastructure
- avoiding external data transmission
- maintaining minimal permissions

---

# Open Source Transparency

Because ContextClock is open source, anyone can:

- inspect the code
- verify privacy claims
- audit behavior
- contribute improvements

Transparency is a core part of the project philosophy.
